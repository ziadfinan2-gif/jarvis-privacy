J.A.R.V.I.S. Privacy Policy

Last updated: November 7, 2026

1. Introduction

J.A.R.V.I.S. is a Windows desktop personal AI assistant. This policy explains how the application handles information when you use its features.

Privacy contact: Ziad.finan2@gmail.com

2. Information Stored Locally

J.A.R.V.I.S. may store conversation history, saved memories, tasks, application settings, and Google authentication information on your Windows device.

Local application data is stored under %LOCALAPPDATA%\JARVIS. Certain sensitive files are protected using Windows Data Protection API (DPAPI), associated with your Windows account.

3. Google Sign-in

J.A.R.V.I.S. uses Google OAuth for account sign-in. It requests basic profile information, including your Google account identifier, email address, and profile name. Your Google password is entered through Google's sign-in page, not collected directly by J.A.R.V.I.S.

The application also requests access to Google's Drive appDataFolder during sign-in, even when cloud synchronisation is disabled.

4. Google Drive Synchronisation

Cloud synchronisation is optional. It requires the user to enable the setting, select "Sync now", and confirm the action.

When synchronisation is performed, J.A.R.V.I.S. can upload:

  • Saved memories
  • Conversation history, limited to the latest 300 entries
  • Tasks

Application settings are not included. The backup is transferred to Google's Drive appDataFolder over HTTPS. The backup is not separately encrypted by J.A.R.V.I.S. before upload.

Disconnecting Google removes locally stored authentication information. It does not automatically revoke Google's authorization or delete an existing cloud backup.

5. Google Search and Web Research

When you request web research, J.A.R.V.I.S. may send your search query to Google Search to retrieve information.

The application checks for certain common sensitive patterns before submitting queries. These checks are not guaranteed to identify every personal or sensitive detail. Google processes search requests under its own privacy policies.

6. Local AI Processing with Ollama

J.A.R.V.I.S. supports local AI processing through Ollama, accessed through your device's local address 127.0.0.1.

In this mode, prompts and conversation context are sent to the local Ollama service rather than directly to a hosted AI model by J.A.R.V.I.S. Downloading models requires a connection to Ollama's model services.

7. Optional OpenAI Integration

J.A.R.V.I.S. also supports an optional OpenAI model. When selected and confirmed, relevant requests and conversation context may be sent to OpenAI. Google Search results may also be included.

The application uses a pattern-based privacy check and sends the request with the setting store: false. This does not guarantee the provider's complete data-retention practices. OpenAI processes submitted information under its own privacy policies.

8. Analytics and Diagnostics

The reviewed application source contains no analytics, telemetry, or crash-reporting upload functionality. Some system information, such as resource usage and network status, is collected locally for display in the application. This statement does not cover Windows or other installed software.

9. Data Security

J.A.R.V.I.S. uses Windows DPAPI to protect certain local files and HTTPS for Google service communications. No security measure can guarantee absolute protection. DPAPI does not prevent access by software already running under the same Windows account.

Google Drive backup files are not separately encrypted by J.A.R.V.I.S.

10. Data Deletion and Disconnection

Users can remove local J.A.R.V.I.S. data by closing the application and deleting its local data folder.

Disconnecting Google removes locally stored authentication information but does not automatically revoke Google's authorization or delete cloud backups. Users should separately delete their J.A.R.V.I.S. backup from Google Drive and revoke the application's access through their Google Account settings.

11. Children's Privacy

Users should avoid submitting sensitive personal information to external services unless they understand how those services process it.

12. Policy Updates

This policy may be updated when application features or data-handling practices change. The latest version will be published on this webpage.
